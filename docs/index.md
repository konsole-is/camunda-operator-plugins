# Plugins

Each plugin has one page. The page tells an admin what the plugin creates, what it needs before the install, and how to configure its chart. It also gives the parameters that a claim can change, the outputs that the plugin publishes, the grants that it writes, what happens when a claim is deleted, and what to do for each reason of a failed condition.

All pages have the same headings.

Plugin authors read [pluginkit](pluginkit.md), the shared library of every plugin.

## Pages

- [Gateway access](plugins/gateway-access.md): host names and Gateway API routes for clusters, Optimize, and management planes.
